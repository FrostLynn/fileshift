# Design Specification: FileShift

## Identity & Purpose
- Product: FileShift, a local-first web file converter.
- Audience: Users, data analysts, and professionals seeking fast, private document conversions between XLSX, CSV, PDF, and DOCX.
- Core Value: Local execution, instant response, data privacy, clear feedback.

## Dials (Liveliness Toolkit)
- ENERGY: 2 (Balanced: purposeful modern productivity utility)
- RHYTHM: 2 (Structured Bento card modules with clear functional differentiation)
- MOTION: 1 (Subtle feedback animations for drag-and-drop, state changes, and modal toggles)

## Overrides
- Override: Bento Grid layout kept per user specification (R-05 override noted).

## Visual Palette
- Dark Theme (Default):
  - Canvas / Background: #0a0e17
  - Card Surface: #111827
  - Card Elevated: #1f2937
  - Border: #1e293b
  - Primary Text: #f8fafc
  - Muted Text: #94a3b8
- Light Theme:
  - Canvas / Background: #f8fafc
  - Card Surface: #ffffff
  - Card Elevated: #f1f5f9
  - Border: #e2e8f0
  - Primary Text: #0f172a
  - Muted Text: #64748b
- Accents & Status:
  - Primary Action / Success: #10b981 (Emerald)
  - Secondary Action / Document Focus: #6366f1 (Indigo)
  - Error: #ef4444 (Rose Red)
  - Warning: #f59e0b (Amber)

## Typography
- Font Family: Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif
- Monospace (only for file size / coordinate metadata): ui-monospace, SFMono-Regular, Menlo, monospace
- Contrast standard: WCAG AA compliant (minimum 4.5:1 for standard text, 3:1 for large text).
